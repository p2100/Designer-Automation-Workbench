# 下载承接 · version

用途：确认应用并选择实际可用渠道。version 是业务页面族，路径可以采用 version、download 等；它不是默认历史版本列表。

## APP-VERSION-001 · hard · 身份连续性

显示同一应用的图标、完整名称和适用平台，让用户能从 detail 确认没有跳错；保留可用返回 detail 的路径。必要的获取条件与当前实体绑定，不在推荐区换成另一个 App 的主下载。

## APP-VERSION-002 · hard · 渠道选择

Google Play、App Store、Android 文件源分别标明平台/来源，按真实能力展示；仅一个渠道也成立。商店商品 ID、包名及实际跳转按公共渠道规则核对，失效目标不能当完成。

APK/XAPK 等格式、已知版本/大小/兼容条件按来源说明；获取策略为 latest 时不补造具体版本。临时链接、外部依赖和必要说明诚实呈现，不把内部管理密钥写进公开页面。

## APP-VERSION-003 · hard · 真实动作与状态

用户选择渠道后执行对应动作。没有浏览器事件/实际证据时不显示“下载已开始/完成/安装成功”；不做假的倒计时、点一次跳回自身的重试或“安全100%”认证。

无法自动观察外部下载时只说明已打开对应渠道，并给真实返回/重试方式；渠道不可用时标明状态，可推荐其他有效平台但不偷换目标。不得为填满三按钮而保留 #/undefined。

## APP-VERSION-004 · hard · 次级内容与手机

保留相关推荐及返回/继续浏览路径；推荐在视觉与动作上次于当前应用的渠道选择，不伪装成下载按钮。手机渠道按钮易于分辨和操作，说明紧邻所属渠道；不保留广告空白。

历史版本仅在有真实记录时添加模块，适用 APP-DATA-006；没有历史数据时不增加空列表，不因此阻断正常承接。相关内容布局自由，不照抄参考主侧栏宽度。

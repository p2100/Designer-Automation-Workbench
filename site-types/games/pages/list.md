# List, search and category

Query, genre, platform/input and result count reflect actual data. Invalid filters recover safely. Search works with keyboard; clear resets both fields/results and URL state. Empty results explain a next action. A category route keeps the correct subset or deliberately navigates when a different genre is chosen.

Preserve useful phone filters. Use ordinary row/card fields suited to scanning; long names and summaries cannot collide with arrows or metadata. Test short search, absent search, zero/one/many results and clear/repaint. Distinct sites still need distinct normal-result grouping.

# Games 最新标准 · 2026-10-27.2

来源：用户 2026-10-27 在统一 Designer-Automation 整合任务中直接提供的 Games 标准。适用于新制作及明确授权的维护/审核；不修改历史冻结包，不把本标准套到 Coupon 或 App（含 App 站中的下载型手游）。owner-requirements.json 中对应稳定 ID 自动进入计划。

## 首页

- 使用满视口宽度布局，左右实际可见边距各 20–40px，不套窄的居中内容壳。游戏图标优先方形（偏好/目标，非强迫拉伸真实图像）。信息在 hover/focus 和明确点击/触控时出现，手机有清楚的查看详情路径，完整可访问名称保留。
- Hover 是否出现按钮由本站设计决定，不能固定所有品牌一套按钮/覆盖层。跨站有实际构图、信息与动作表现差异。
- **首页不出现分类模块。** 旧版“首页发现之后必须分类浏览”已撤销；分类独立页仍按真实数据维护，不因这条删除既有正常路由。
- 背景的图案、纹理、几何分割或插画要有游戏主题逻辑，精致、克制、不抢游戏主体；检查从顶部到页脚的整体衔接，不出现无意义图形或突兀断层。

## Detail

- 页面顶部有一行真实游戏图标推荐，使用本站主题风格，图标分别进入对应游戏；放在主体身份前并检查 PC/手机横排容量。“部”按顶部理解。本条消息没有随附新图片，不伪造图中坐标或声称已逐像素对图。
- **Detail 和游戏页 PC 主体内容容器为 1200px**；可用宽度不足时随屏幕收缩，不制造手机溢出。旧 1180px 等为历史参考观察，不再控制新候选。
- PC 的 How to play 默认单列，不做两列。正文在其所属内容容器内充分占宽后自然换行，不用窄的 ch/max-width、无意义嵌套层或硬换行提前截断。
- **Sky Swarm 是待定位的具体布局缺陷。** Agent 先找到实际站点、当前构建和模块，检查身份、操作、图像、How/正文、推荐及相邻模块的阅读顺序和尺寸，再修复与复查。同名游戏不自动证明同一问题；缺精确截图不编造原异常几何，不把一句规则当成已经修复。

## 游戏页

- 底部游戏信息与页面主体内容使用同一宽度与对齐，不能落进更窄的无关轨道。
- Loading 背景用 **Image 生图**制作有游戏氛围的精致扁平插画，按品牌与游戏构图，落地本地图片、来源/生成记录和实际引用。加入有目的的动效与 loading 进度条，尊重 reduced-motion。
- 进度可观测时绑定真实加载/引擎进度；不能观测时用明确的不定进度条，不伪造百分比、定时填满或完成。iframe load 不代表游戏就绪，失败与重试必须真实。
- **PC 不显示全屏按钮；不显示单独返回 detail 的按钮。** 浏览器返回、离开/恢复和失败重试保持可用，不把玩家困在游戏内。

## 整体

- 手机所有真实可点击位置都有可见的按下/触控反馈，包含卡片、链接、图标、菜单、搜索结果、分页及游戏外壳操作。逐项清点并实际触控，不能用桌面 hover 截图代替；动画不推挤邻项，减少动态模式仍有状态反馈。
- 模块标题区只保留标题，不附加介绍性/装饰性描述文案。游戏说明、How to play 正文、真实条件、必要状态与错误信息仍在各自内容职责内保留，不能把本条解释为删除核心内容。
- 按钮用更鲜亮、纯度更高且与页面协调的游戏配色，检查最终对比度和状态；下载分支既有官方平台识别/专属颜色要求保留其范围，不再把旧 web-play 配色方向当统一皮肤。
- 新做或授权替换的游戏/游戏操作图标用 **Image 生图**生成精致线性图标，线宽、尺度、留白和风格一致，保存本地素材和生成证据。生成的游戏图标/编辑插画要绑定实际游戏，不能冒充官方截图；官方平台标识和真实产品截图保留对应身份。
- 全站文案撑满其所属内容容器再自然换行；保留语义段落、安全长词换行和已明确的普通名称单行省略，不用缩字或隐藏正文处理空间问题。
- **手机所有可见文字最大 24px**，含标题、导航、按钮、标签和状态；原可读性下限仍生效。用布局/层级解决容量，不用隐藏文本规避。

## 在设计师电脑执行

Agent 负责识别源码、真实构建命令、浏览器、Image 工具与反馈存储，不让设计师选规则或填 JSON。结构工具 Node 22+；浏览器和 Image 用宿主实际可用能力，不依赖原作者路径/账号/兄弟目录。Image 生成能力缺失时保留已有合规素材并完成可做的布局修复，新增/重做素材记 not-run，不能用 CSS 几何图形或随手下载替代明确生图要求。

读取 bin/inspect-games.mjs，将 inspectGames 作为只读 browser.evaluate 探针运行；选择器从实际候选绑定，见 docs/portable-review.md。它测量可确定的容器/字号/布局并列出点击位置，不裁定背景审美、生图来源、触控反馈、真实进度或游戏运行。按 owner-requirements 的所有适用项实看与操作，未执行保留 not-run；截图、反馈原话、修复和复查绑定同一候选保存。
